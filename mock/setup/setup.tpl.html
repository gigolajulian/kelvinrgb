Three pieces run your lights and fans

Lighting OpenRGB 1.1

Talks to the lights on your RAM, graphics card, cooler, board and hub. KelvinRGB runs it quietly in the background.

Installs to Program Files\OpenRGB · 49 MB · GPL-2, source at codeberg.org/OpenRGB

Driver PawnIO 2.2

A signed driver that lets KelvinRGB read the board's sensor chip: temperatures, fan speeds and fan headers.

Kernel driver from pawnio.eu · 3.4 MB · asks Windows for admin once

Fan control Sensor service

Reads every sensor and drives your fan headers. Fans never drop below 25%, and go back to BIOS when KelvinRGB closes.

Built into KelvinRGB · LibreHardwareMonitor 0.9.6 · needs KelvinRGB started as admin
